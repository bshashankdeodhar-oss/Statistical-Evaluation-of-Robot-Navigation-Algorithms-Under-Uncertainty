# Data Dictionary: Robot Navigation Benchmark Dataset

This document defines the variables and schema for simulation results generated by the **Statistical Evaluation of Robot Navigation Algorithms Under Uncertainty** framework.

Files documented:
- `data/benchmark_navigation_dataset.csv`
- `data/condition_summary_metrics.csv`
- `results/experiment_results_*.csv`

---

## Variable Definitions

| Column Name | Data Type | Units / Range | Description |
|:------------|:----------|:--------------|:------------|
| `trial_id` | Integer | 1, 2, 3... | Unique identifier for each simulation trial |
| `map_id` | Integer | e.g. 101, 102 | Unique identifier for the underlying 2D grid obstacle map |
| `algorithm` | Categorical | `Dijkstra`, `A*`, `Risk-Aware` | Path planning algorithm evaluated |
| `lambda_risk` | Float | 0.0 to 5.0 (default: 0.5, 1.0, 2.0) | Risk aversion weight balancing travel cost vs. hazard exposure |
| `replanning` | Boolean | `TRUE` / `FALSE` | Indicates whether dynamic online replanning was enabled upon encountering unexpected edge blockages |
| `obs_density` | Float | 0.05 to 0.50 (e.g. 0.10, 0.20, 0.30) | Proportion of grid cells occupied by static obstacles |
| `uncertainty_level` | Float | 0.0 to 0.50 (CV) | Coefficient of variation for Gamma-distributed edge traversal cost noise |
| `disruption_prob` | Float | 0.0 to 0.40 | Per-step probability of a planned traversable edge becoming dynamically blocked |
| `sensor_error` | Float | 0.0 to 0.20 | Rate of false positive obstacle detection and false clearance perception |
| `grid_width` | Integer | Typically 20 (range: 10-60) | Width of the 2D grid world in discrete cells |
| `grid_height` | Integer | Typically 20 (range: 10-60) | Height of the 2D grid world in discrete cells |
| `planning_success` | Boolean | `TRUE` / `FALSE` | Indicates whether the planner found a valid path from Start to Goal on the initial map |
| `execution_success`| Boolean | `TRUE` / `FALSE` | Indicates whether the robot physically traversed from Start to Goal without being trapped |
| `overall_success` | Boolean | `TRUE` / `FALSE` | Joint success indicator (`planning_success && execution_success`) |
| `nominal_cost` | Float | >= 0.0 | Planned path traversal cost under nominal, noise-free conditions |
| `realized_cost` | Float | >= 0.0 (or NA on failure) | Actual cumulative cost incurred during simulated physical execution |
| `path_length` | Integer | >= 0 | Number of discrete grid transitions in the planned route |
| `nodes_expanded` | Integer | >= 0 | Total number of graph vertices popped from the priority queue (computational workload) |
| `planning_time` | Float | Seconds (wall-clock) | Time elapsed during path planning computation |
| `n_replannings` | Integer | >= 0 | Number of dynamic replanning events triggered during traversal |
| `failure_reason` | Categorical | `none`, `blocked`, `max_steps_exceeded`, `disconnected` | Diagnostic category if overall success was FALSE |
| `env_seed` | Integer | Discrete integer | Exact pseudorandom seed used for environment realization (stochastic noise & disruptions) |
| `condition_id` | Integer | 1, 2, ... | Index of the unique factorial combination of experimental parameters |

---

## Condition Summary Metrics (`condition_summary_metrics.csv`)

Aggregated statistics calculated across independent maps and trials for each condition cell:
- `n`: Total trials in cell
- `n_success`: Total successful trials
- `success_rate`: Proportion of successful trials
- `mean_nominal_cost` / `sd_nominal_cost`
- `mean_realized_cost` / `sd_realized_cost`
- `mean_nodes_expanded` / `sd_nodes_expanded`
- `mean_planning_time` / `sd_planning_time`
- `ci_lower` / `ci_upper`: Wilson score 95% confidence intervals for route success rate
